# 💖 دفتر ذكريات سما (صمصم)

موقع تفاعلي ثلاثي الأبعاد (HTML / CSS / JS) بتصميم بينك ناعم وأنيميشن تقليب الصفحات، مخصص لـ **سما (صمصم)** لحفظ الصور، الرسائل، الأغاني، والمحادثات الجميلة.

## 📁 الملفات
- `index.html` — الصفحة الرئيسية للدفتر.
- `style.css` — التصميم البينك، تأثيرات الـ 3D، والأنيميشن.
- `app.js` — منطق تقليب الصفحات، الصوت، الاستوديو، وتكبير الصور.
- `memories-data.js` — ملف البيانات (الغلاف، رابط الموسيقى، والصفحات).

## 🚀 طريقة الرفع وإضافة ذكرياتك على السيرفر
عندك طريقتين سهلتين جداً:

### الطريقة الأولى (الأسهل من داخل الموقع):
1. افتح `index.html` في المتصفح.
2. اضغط على زر **✨ إضافة ذكرى** في الأعلى.
3. أضف الصور والرسائل والأغاني اللي تحبها، وعدّل عنوان الغلاف أو رابط الموسيقى من تبويب **إعدادات السيرفر والموسيقى**.
4. اضغط على **⬇️ تحميل memories-data.js**.
5. استبدل ملف `memories-data.js` القديم بالملف الجديد وارفع المجلد كله على السيرفر!

### الطريقة الثانية (بوضع الصور في مجلد على السيرفر):
1. أنشئ مجلد باسم `images` ومجلد باسم `audio` بجانب `index.html`.
2. ضع صورك في `images` وملف الأغنية في `audio`.
3. في استوديو الموقع (أو داخل `memories-data.js` مباشرة)، اكتب مسار الصورة مثل `images/pic1.jpg` ومسار الأغنية مثل `audio/song.mp3`.
